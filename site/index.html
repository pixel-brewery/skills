Install a skill

Run this command in your repository to add Architekt to Codex.

npx skills add pixel-brewery/skills --skill architect --agent codex --copy --yes

Use designer or technical-writer in place of architect to install another skill. To pin an exact version for your team, install a full commit SHA and commit the files and lockfile produced by the CLI.
